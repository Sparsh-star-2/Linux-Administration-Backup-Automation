# Linux Administration Backup Automation

A Linux system administration automation project using Bash scripting to perform backup operations, user management, permission setup, and system health monitoring.

## Project Overview

This project demonstrates practical Linux administration skills by automating common system administrator tasks using shell scripts.

The automation scripts help manage:

- Application backup creation
- User management
- File permission configuration
- System health monitoring
- Logging of administrative activities

## Features

### 1. Automated Backup System
- Creates compressed backup archives using `tar`
- Stores backups with timestamp-based filenames
- Maintains backup logs

### 2. User Management Automation
- Automates Linux user-related operations
- Reduces manual administration effort

### 3. Permission Management
- Automatically configures required file permissions
- Helps maintain proper access control

### 4. System Health Monitoring
- Checks system information
- Generates health reports
- Maintains monitoring logs

## Technologies Used

- Linux (Ubuntu)
- Bash Shell Scripting
- Git & GitHub
- AWS EC2
- Linux File System
- Tar Backup Utility
